## Key decisions already made (do not re-litigate)

- **Cover priority:** self-hosted local file always wins; Apple Books is the preferred API, Open Library is last resort (it serves Amazon "Look Inside" overlays and keyline-bordered scans — the source of every bad cover this session)
- **Self-hosting covers** is the durable fix for bad/inconsistent covers — download once to `/public/library/`, never hotlink publisher/Amazon CDNs
- **Rosenfeld covers** come from a clean publisher CDN and have **no scan borders** — do not run the border trimmer on them (their dark design bands are content, not frames)
- **Grid is visual-only** — no title/author under covers; metadata lives on the detail page
- **Doorbells, Danger, and Dead Batteries** author is intentionally **Steve Portigal** (user set this)
- **No em dashes** in user-facing copy; **no dark mode**
- **Secrets** (`NOTION_API_KEY`, `NOTION_LIBRARY_DS_ID`) live only in `.env.local` — never paste tokens in chat
